# QA of the INFER dapp (infer.imdusd.com), 2026-10-06

In-house, Claude Fable 5.1, against the uncommitted `web/infer` + `web/src/infer` tree on top of `fbce58a`. Two
streams: a static, accessibility, responsive and content pass over the three pages in their pre-launch state
(a review agent, ~60 screenshots and logs under the session scratchpad), and a live-flow pass in which the
dapp was driven in Chromium by an injected wallet against an anvil fork of mainnet with the reference
contracts from `fa11up/infer-token` deployed around IMD standing in for INFER. Everything found was fixed in
the same tree except where noted; the "after" state is what is recorded.

## Pages and build

- `/` trade (left) and stake (right), one screen; `/claim/`; `/tokenomics/`; `/404.html`. Built by
  `vite build --mode infer` into `dist-infer/`, checked by `scripts/infer-check.mjs`, served by its own
  Worker (`wrangler.infer.jsonc`, `not_found_handling: 404-page`).
- Figures and addresses come from `web/src/infer/launch.json` (private until the launch request, gitignored;
  `launch.example.json` ships with every figure null). The build picks whichever exists.
- CSP per page: `default-src 'none'; script-src 'self' 'sha256-<theme bootstrap>'; style-src 'self';
  img-src 'self' data:; connect-src 'self' <the launch file's RPCs and claim-file origins>; frame-ancestors
  'none'; base-uri 'self'; form-action 'none'; object-src 'none'`. Hash verified independently against the
  one inline script in each page; zero violations with the policy injected.

## Live flows on a mainnet fork (all pass)

Harness: an EIP-1193 provider injected into the page forwards JSON-RPC to the fork, which impersonates the
account, so the page's own viem code prepares every transaction and anvil mines it. Reference contracts
deployed: `StakedInfer`, `InferDripper`, `SeasonVault` (season 0 ended by advancing the clock, root set
through the governor's 48-hour path), `LegacyRedeemer` with two mock burnable tokens for MIYA and MXXN; IMD's
real ETH pool as the launch pool.

## Found and fixed

1. **Pool price displayed inverted** (`App.tsx`, `swap.ts`): "pair per INFER" inverted when INFER was
   currency0 and not when it was currency1, wrong in both orderings; the harness had only checked for
   digits. Fixed; a unit test pins both directions against the live pool's slot0 word.
2. **Errors shown once per page load**: the vanishing error was keyed by its text and never cleared, so a
   repeated wallet rejection or quote failure showed nothing. Notices now carry a serial and clear
   themselves when they leave; verified a second identical error reappears.
3. **Swap deadline and Permit2 expiry from the browser clock**: a skewed clock (the fork's, or a user's)
   reverted every swap with `TransactionDeadlinePassed`. Both now come from the latest block's timestamp,
   as does the claim page's "season over" test.
4. **No refresh on new blocks**: after staking, "Wait one block" stayed until a reload. The app and claim
   pages re-read the chain every twelve seconds while live.
5. **No-scroll broke on short screens** (1280x650 and below): the page scrolled instead of the panes. The
   app shell now has a definite height and the panes scroll inside it; verified at 1280x600.
6. **Stake tiles left an empty cell** at widths of 860 px and below. The last tile spans.
7. **Negative and exotic amounts** parsed (`-5`, `1e5`, `1.2.3`) and could enable buttons. One parser
   accepts only plain positive decimals, forgives thousands separators and spaces; tested.
8. **Unstake silently capped** to what the one-block hold allowed and executed a different amount than
   shown; "Wait one block" was enabled. The button is now disabled while the hold covers the amount.
9. **A failed receipt wait dropped the hash** and read as a failure although the transaction may have
   mined. The hash and receipt link are kept, with "could not confirm it" wording.
10. **Failed reads left the page silently stuck**; stale balances survived a side switch. State is reset
    while reading, failures surface as a vanishing notice, and buttons read "Reading…" until data is in.
11. **Double submit**: two clicks before a re-render could start two sends. A ref guard ignores the second.
12. **Accessibility**: Buy/Sell and Stake/Unstake tabs now take arrow keys with one tab stop; the
    receive output has a name; the stats grid is a labelled group; the nav keeps "imdUSD" casing.
13. **Copy and typography**: "30 day" became "30-day"; "3x" became "3×"; opening cap reads 14,444 on both
    pages; long tokenomics paragraphs use `text-wrap: pretty` (no one-word last lines at 390 px); ledger
    small print no longer wraps mid-leader; a wallet that authorises no account gets a plain message.
14. **Site hygiene**: a 404 page with absolute links, a sitemap, and a robots entry; `launch.example.json`
    formatted; the build plugin honours `--outDir` so a QA build can live beside the real one.

## Known and left

- `/tokenomics/` loads the shared chunk with viem (523 kB, 158 kB gzip) through the shell's wallet hook; a
  split would cut its JavaScript about fivefold.
- If Cloudflare's Web Analytics injection is on for the zone, the CSP will block its beacon here as it does
  on imdusd.com (console error, no functional effect).
- `manifest.webmanifest` colours are fixed to the light palette.
- Pre-launch only the structure can be seen: every action reads "opens at launch" until `launch.json`
  carries the token, pool key, and contract addresses. MIYA's address is still null in the private file.
- The fork test (`tests/swap.fork.test.mjs`) needs an anvil fork on :8545 and skips otherwise; a fork that
  has aged past the upstream node's non-archive window fails its storage reads (seen once; restart the fork).
