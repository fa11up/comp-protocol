# imdUSD launch cue

`imdusd-anthem.wav`: 10.000 s, 48 kHz, 16-bit stereo; `imdusd-anthem.m4a` is an AAC copy for phones.
Synthesized from scratch by `anthem.py` (numpy + scipy, no samples): rebuild with
`python3 marketing/music/anthem.py`.

Phonk drums, an 808 and a cowbell riff in F# Phrygian, an Evangelion-style alarm pad, command-center
data blips, a build with a gap and a reversed cymbal, then **the hit at exactly 6.500 s**: brass braam,
sub boom, stamp, cash-register ka-ching and a sword shing (its scrape starts 0.16 s before the hit).
The braam rings out into a clean F# minor while the groove continues low-passed under the end card and
fades to silence by 9.95 s. 147.69 BPM, so the hit lands on a downbeat. Peak −1 dBFS, no clipping.

Replaces the swarm's two stings (`marketing/sting/`), which were too plain for the launch.
